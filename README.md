# FinalShell Rust Rewrite

An independent Rust rewrite of FinalShell.

## Development

Requirements:
- Rust stable
- Cargo

Run:

```bash
cargo build
cargo test
cargo run
```

## Supported target platforms

- macOS ARM64
- macOS x86_64
- Linux x86_64
- Linux ARM64
- Windows x86_64

Cross-platform builds and checks are performed by GitHub Actions.

## Project status

Early development. The application architecture and feature compatibility
are being evaluated before implementation.

The original Go project is maintained separately and is not included
in this repository.
